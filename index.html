PlayStation 1 game development

psxsplash is everything you need to make a PlayStation 1 game: an editor, an engine that runs on real hardware, and the pcsx-redux emulator, in one download. No other tools to install.

Windows, macOS and Linux. The nightly build is rebuilt from every push; tagged versions will be listed on the releases page.

Scripting with blocks

Build game logic from blocks

The block editor is a full way to script a psxsplash game, on equal footing with Lua. The inspector offers New blocks and New Lua side by side; pick whichever suits the script.

Events, control, objects, sound

The palette groups blocks into events, control, objects, sound and scenes, variables, operators, input and debug. Drag a block under a hat and it snaps into the stack.

Picked from the scene

Object, sound and cutscene fields are chosen from lists of what the scene contains, so a name cannot be mistyped. Variables are made in their own column.

Lua you can read

The Lua a .blocks script turns into is shown beside the canvas as you edit, and that Lua is what runs on the console. Blocks that wait run as coroutines.

The editor

Everything for a PS1 scene in one window

Scripts, models, textures, UI and cutscenes are all edited in the same window, next to a view that draws like the console.

Lua

A Lua editor that knows the API

Lua scripts open in tabs beside the scene. Completion lists the psxsplash API with each function's signature and a one-line description, along with the locals and functions in scope.

Syntax errors are marked on their line as you type. Find and Replace handles regex, case matching and replacing inside a selection.

Import

Models and textures

Drop a .glb, .gltf, .fbx, .obj or .blend file onto the editor (.blend needs Blender installed). Embedded textures come in with the model, and skinned rigs import from glTF and FBX.

The inspector puts each texture next to the pixels the PS1 will draw, with its bit depth, palette use and VRAM cost. When a texture would keep every colour at 4 bpp, it says so and converts it in one click.

Viewport

See the PS1 while you edit

The scene view renders at 320x240 with 15-bit dithering and affine texture mapping. Switch to Clean when you need to see the geometry.

VRAM, SPU RAM, main RAM and the triangle count sit in the status bar and update as you add content. The scene tree shows each mesh's triangles, and the viewport draws trigger, interact and navigation overlays.

Play

Play, Run on hardware, Export

Play (F5) builds the scene and boots it in the bundled pcsx-redux, shown in the Game panel next to the scene view.

Run on hardware (Ctrl+F5) uploads the same build over serial to a PlayStation running Unirom or psxmon and shows its output. Export writes a disc image of every scene in the build list.

Build > Performance Overlay adds an FPS counter and heap bar to the running game. Room Debug Overlay draws room wireframes.

UI

UI canvas editor

Lay out HUDs and menus on a 320x240 canvas from boxes, text, progress bars, lines and images, anchored to the screen edges. Text uses the system font or up to three of your own TTF, OTF or bitmap fonts.

Elements are driven from Lua and from cutscene tracks, and a canvas can be the scene's loading screen. The editor warns when the console will draw an element differently from how it looks.

Timeline

Cutscenes and animations

Key camera, object, light, UI and rumble tracks on a timeline, with linear, step and ease curves, plus audio and skinned-animation events. Scrubbing poses the scene view at that frame.

Lua starts them with Cutscene.Play and Animation.Play; up to eight animations run at once.

Also in the editor

Navigation and rooms

The export builds navigation regions and portals, and the viewport outlines them. Room and Portal components cull interiors room by room.

NPC agents

The Agent API moves NPCs to targets, follows patrol waypoints and gives them vision and hearing ranges.

Audio

WAV files are encoded to SPU ADPCM on export, and their size counts against SPU RAM in the status bar. Play clips with volume and pan from Lua or cutscenes.

Skinned meshes

Rigged models and their clips are baked to bone matrices at a rate you set. The inspector lists bones, triangles and each clip's size.

Lights

Lights bake into vertex colours, or run on the GTE at runtime with up to four per mesh. Light tracks animate them in cutscenes.

World streaming

One switch splits static geometry into regions on a grid and streams them from the disc. Collision, navigation and scripts stay resident.

Memory cards

Set the region, product code, save title and icon in the scene inspector. Lua saves and loads tables as standard memory card files.

Serial multiplayer

The Net API connects consoles over the serial port, by link cable or to a PC, and replicates players and shared objects.

The engine

psxsplash runs on the console

A C++ engine built on PSYQo. It runs your game on real PS1 hardware or in an emulator, and an exported game only compiles in the subsystems its scenes use.

GTE rendering

Geometry goes through the GTE in fixed point. Scenes are culled against a BVH, or by rooms and portals once you add rooms.

Loads from disc or PCdrv

The same game loads scenes from a CD-ROM image or over PCdrv from an emulator or serial cable.

Only what you use

Subsystems a game does not use are left out of the binary. A script calling into one gets an error that names the feature.

Game logic in Lua

Scripts respond to events: collisions, triggers, interactions, button presses, objects being enabled or destroyed. There is no game loop to write.

The same events are the hats in the block editor, so a script can start as blocks and a teammate can read the Lua it makes.

Lua API in the documentation →
collectible.lua 
local collected = false

function onCollideWithPlayer(self)
    if collected then return end
    collected = true

    Entity.SetActive(self, false)
    Audio.Play("pickup", 100, 64)
end
Get started

Three steps

1

Download

Get the archive for your OS from the nightly release. Per-OS notes are on the release page.

2

Unpack and open the example

Run splashedit from the unpacked folder and open examples/courtyard.

3

Press Play

The scene builds and starts in the Game panel. Edit, press Play again.
