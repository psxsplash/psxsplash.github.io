SplashEdit NG

Make PS1 games.
Press Play.

A standalone scene editor for the psxsplash engine. One download includes the editor, the engine and the pcsx-redux emulator. No other tools to install.

Download SplashEdit NG Documentation

Windows, macOS and Linux. The nightly build is rebuilt from every push; tagged versions will be listed on the releases page.

The editor

See the PS1 while you edit

The editor shows what the console will do while you work, so problems turn up before you build.

PS1 viewport

The scene view renders at 320x240 with 15-bit dithering and affine texture mapping. Switch to Clean when you need to see the geometry.

Memory budgets

VRAM, SPU RAM, main RAM and triangle count sit in the status bar and update as you add content.

Texture checks

The inspector compares each source texture with its PS1 version and flags textures that fit a smaller bit depth, with a button to convert them.

Scene overlays

Trigger, interact and navigation overlays are drawn in the scene view, so you can see where the player can walk.

One click

Play, Run on hardware, Export

Play builds the scene and boots it in the bundled pcsx-redux, shown in the Game panel next to the scene view.

Run on hardware boots the same build on a PlayStation. Export produces a disc image.

Build > Performance Overlay adds an FPS counter and heap bar to the running game. Room Debug Overlay draws room wireframes.

The engine

psxsplash runs on the console

A C++ engine built on PSYQo. It runs your game on real PS1 hardware or in an emulator, and an exported game only compiles in the subsystems its scenes use.

  • Lua scripting
  • Rendering
  • Collision
  • Navigation
  • NPC agents
  • UI
  • Audio
  • Cutscenes
  • Animations
  • Skinned meshes
  • Sprites
  • Lights
  • Streaming
  • Memory cards
  • Networking
  • Multiple scenes

Game logic in Lua

Scripts respond to events: collisions, interactions, button presses, timers. There is no game loop to write.

Lua API in the documentation →
collectible.lua 
local collected = false

function onCollideWithPlayer(self)
    if collected then return end
    collected = true

    Entity.SetActive(self, false)
    Audio.Play("pickup", 100, 64)
end
Get started

Three steps

1

Download

Get the archive for your OS from the nightly release. Per-OS notes are on the release page.

2

Unpack and open the example

Run splashedit from the unpacked folder and open examples/courtyard.

3

Press Play

The scene builds and starts in the Game panel. Edit, press Play again.
